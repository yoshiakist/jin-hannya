`npm run build`（グラフ検証 → グリフ前計算 → 型検査 → 本番ビルド）は通る。

チェックは**画面で確認できたものだけ**に付ける。実装しただけで未確認のものは外したままにし、その状態を「実装済みだが未確認」に書く。

## 完了している

| 領域 | 状態 |
|---|---|
| ビルド基盤 | Vite + TS + React 19 / r3f v9 / three 0.185。`WebGPURenderer` を async 初期化し、WebGPU が取れなければ WebGL2 バックエンドへ落ちる。init 後に実バックエンドを見てティアを訂正する |
| YAML | ビルド時に JSON へ変換する自作 Vite プラグイン。ランタイムに YAML パーサを載せない |
| グリフ前計算 | `scripts/build-glyphs.ts`。SVG パース → 平坦化 → 穴の判定 → 三角形分割 → 面積重み付きサンプリングまで自前（依存は three の `ShapeUtils` のみ）。118 字 + 円相 = 119 件、mesh 約 5.7MB / 粒子 49.2 万点 |
| グロー用 SDF | `scripts/sdf.ts`。8SSEDT で 64×64 / 字の 8bit アトラス（1024×512、約 0.5MB）。発光の縁が字形をなぞるのはこれによる |
| 円相 | `Y` 反転・非正方形 viewBox・断片パス約 40 本を含めて取り込み済み |
| コンテンツ | 15 ノードの YAML + 15 本の解説 Markdown。zod スキーマ + 静的検証 |
| `L0` | 格子、字ごとの位相をずらしたゆらぎ、hover で句の範囲だけが琥珀に光り周囲が沈む。範囲が列をまたぐ見え方も仕様どおり |
| `L1` 以降 | 3 種のレイアウト。`none` は 2 列折り返しの大書、`circle` は円相 + 円周配置、`column` は角丸矩形 + 箱のあいだだけを繋ぐ縦線 |
| DOM レイヤー | 縦書きの解説・サマリー（淡いオレンジの罫つき）・読み／梵語・現在位置インジケータ・読み上げボタン・左矢印。位置は `overlayInsets` の 3 つの目印から CSS が組む |
| ナビゲーション | 相を持つ FSM、ハッシュルーティング、ブラウザバック = ズームアウト |
| 遷移演出 | 持ち越しの字がメッシュのまま出発点から行き先へ移り、残りは粒子となって上へ流れて消える／凝集する。カメラも同じ時計・同じカーブで動く |
| 遷移中の引っかかり | 解消。紙面を畳まず、マテリアルも紙面で 1 本にして、面の用意を二度としない |
| 墨とゆらぎ | 手続き的な墨のムラ（`inkDensity`）と、全深度で共通のゆらぎ（`sway.ts`） |
| `L1` のカメラ | 大書が右へはみ出す画面では視野ごと右へ送る（`nodePanX`）。潜るあいだは等倍へ戻す |
| `L1` 以降のパン | 狭い画面で左へはみ出した本文をドラッグで左右にだけ辿れる。ばねは atom 側に 1 つだけ |
