# 見た目 — 墨・光・ゆらぎ

色は `src/scene/materials.ts` と `src/styles.css` のトークンから引く。**有彩色は琥珀（`--focus`）と青白（`--visited`）の 2 つだけで、これ以上足さない。** 2 つは役割で分かれる — 琥珀 = いま触れている一時的な状態、青白 = もう下りた残り続ける痕跡（→ `reading-progress`）。

## デザイントークン

```css
:root {
  /* 面 */
  --bg:            #050505;  /* ほぼ黒。完全な #000 ではなく僅かに浮かせる */
  --vignette:      radial-gradient(ellipse at 50% 50%, #0a0a0a 0%, #000 85%);

  /* 文字 */
  --ink:           #f2f0ec;  /* 大書・筆文字。わずかに温かい白 */
  --text:          #d8d5cf;  /* 解説本文 */
  --text-dim:      #8e8a84;  /* 読みガナ・梵語・補助 */
  --rule:          #b98a4a;  /* サマリーの区切り罫。淡いオレンジ */

  /* 状態 */
  --focus:         #ffd08a;  /* hover / 選択の琥珀 */
  --focus-glow:    #ffb85c;  /* グローの芯 */
  --visited:       #9ec4f5;  /* 読破した語の青白（L0 だけ） */
  --visited-glow:  #5b9bf2;

  /* 図形 */
  --stroke:        rgba(242,240,236,.55);  /* 円相・矩形枠・連結線 */
  --stroke-hover:  var(--focus);
}
```

- 彩度は全体で極端に低い。
- 白の使い分けは 3 段（`--ink` > `--text` > `--text-dim`）。**この階層が奥行きを作っている。**

## hover の発光（琥珀グロー）

- グローは 2 段（近距離の強い滲み + 遠距離の弱い滲み）。DOM 側は `text-shadow`。
- **WebGPU 側はビルド時に焼いた字ごとの符号付き距離場（SDF）を引き、輪郭からの距離で減衰させる**（`createGlowMaterial`）。**板の中心から放射させると、字が違っても同じ丸い光になり、「字が光っている」ではなく「字の裏に電球がある」絵になる。**
- 届く距離は `GLOW_NEAR` / `GLOW_FAR`、濃さは呼び出し側（L0 は `GLOW_STRENGTH`、大書は `GLOW_OPACITY`）。
- 発色・減光・グローは 0.4 秒（`FOCUS_FADE`）かけて渡す。
- **`instanceColor` は使わない。** `WebGPURenderer` のノードマテリアル経路で期待どおりに効かない。インスタンス属性 + TSL で書き、Tier 1 / Tier 2 で同じ結果になるようにする。
- 図形での出し分け: `circle` は文字のみ発光、`column` は文字 + 枠線の両方を発光させる。

## 読破の青白（L0 のみ）

同じ距離場の仕掛け（`SdfGlow`）を色と強さだけ替えて使い回す。**触れているあいだは琥珀が勝つ**（青白の上に琥珀を混ぜる）。明滅させず点いたままにし、`VISITED_GLOW_STRENGTH` は琥珀の `GLOW_STRENGTH` よりはっきり弱く保つ（上げると紙面がイルミネーションになり、いま触れている字が読めなくなる）。判定と狙いは → `reading-progress`。

## 墨の質感

グリフの塗りは均一な白ではなく、**濃淡とかすれのある墨**（`inkDensity`）にする。テクスチャは持たず、すべて手続き的に出す。色は増やさず、既存トークンの明度と不透明度だけを揺らす。

- 成分は 3 つ。にじみ・墨だまりの大づかみな濃淡／紙の目／筆の流れに沿って引き伸ばしたかすれの筋。
- **模様の粗さはワールド単位で一定にする。** 字の大きさに比例させると、大書では筋が太くなりすぎて墨ではなく金属の光沢に見える。字面ローカル座標にその字のワールドでの大きさを掛けてから引く（座標は字と一緒に動くので、ゆらぎで模様が泳ぐこともない）。
- 種は字（インスタンス）ごとに振る。同じ字が紙面に何度現れても刷り物に見えない。
- 最も薄いところでも一定の濃さを残す。0 まで落とすと字が穴だらけになる。

## ゆらぎ

紙面（L0）も大書と図（L1 以降）も、遷移で持ち越される字も、**同じ規則で揺れる**。どの深度でも「同じ場に浮かんでいる」と見えることが要点なので、規則は 1 か所（`scene/sway.ts`）だけが持つ。

- **振れ幅は字の大きさに対する比**で持つ。絶対値にすると、大書のような大きい字では揺れが相対的に消えて固まって見える。
- 位相は字ごとにずらす（揃うと紙面が波打つ）。種は紙面が全文インデックス、大書と図が字のコードポイント。**墨と滲みが別メッシュに分かれても、遷移で出発点と行き先に分かれても、同じ種から引き直せば揺れの位置ごと繋がる。**
- x / y / 傾きで周期をわずかにずらし、単純な往復に見せない。

## タイポグラフィ

| 用途 | 書体 | 組み |
|---|---|---|
| 大書・図中の文字 | 筆文字（`assets/svg/` の 118 字） | 縦組み。WebGPU レイヤーで描画 |
| 解説本文・サマリー | 明朝系（可読性優先） | `writing-mode: vertical-rl`。DOM レイヤー |
| 読み・梵語 | 同上・極小 | 縦組み・字間広め。ラテン翻字は縦中横にせず縦に流す |
| 現在位置インジケータ | ゴシック or 明朝（可読性優先、筆文字にしない） | 縦積み |

## グリフの前計算（演出の核）

**ランタイムで SVG を触らない。** 各文字について、**ビルド時に**（`scripts/build-glyphs.ts`）SVG から 3 つの表現を生成しておく。これがスマホ性能上の要点。

1. **メッシュ** — パス → 平坦化 → 穴の判定 → 三角形分割。通常表示・hover 発光用。フィルは TSL マテリアルで墨のかすれ・にじみを付与。
2. **粒子サンプル** — 塗り領域から面積重み付きでサンプリングした座標配列（バイナリで同梱）。散開 ⇄ 再凝集の「ホームポジション」として使う（→ `transition-fx`）。
3. **符号付き距離場** — メッシュを高解像度の内外マスクへラスタライズし、8SSEDT で符号付き距離を出して 64×64 / 字の 8bit アトラス（1024×512）に焼く（`scripts/sdf.ts`）。**発光の縁が字形をなぞるのはこれによる。**

118 字 + 円相 = 119 件、mesh 約 5.7MB / 粒子 49.2 万点 / SDF 約 0.5MB。依存は three の `ShapeUtils` のみ。

出力は `src/generated/`（索引）と `public/glyphs/`（`mesh.bin` / `particles.bin` / `sdf.bin`）。**どちらも生成物でコミットしない。** clone 直後は `npm run content:build` を先に走らせる。

## 円相（`assets/pattern/circle.svg`）

`layout: circle` の外周はこの素材を使う。**手続き的生成はしない。** 形式がグリフ SVG と異なるため専用の読み込み経路が要る。

| 項目 | 値 | 対応 |
|---|---|---|
| 生成元 | potrace 1.15 によるトレース | — |
| `viewBox` | `0 0 1273 1280` | ほぼ正方形だが**正確な正方形ではない**。アスペクトを保って配置する |
| `fill` | `#000000` | **黒で書かれている。** 形状のみ取り、描画時に `--ink` を当てる |
| `transform` | `translate(0,1280) scale(0.1,-0.1)` on `<g>` | **Y 軸が反転している。** 適用を忘れると上下が逆になる |
| パス構成 | 長大なパス 1 本 + 微小な断片パス **約 40 本** | 断片は筆のかすれ・飛沫。**間引かずに全て使う**（質感の源） |
| 形状 | 正円ではなく、線幅が場所により変化する閉領域（塗り） | ストロークではなく塗り図形として扱う |

- ビルド時に `build-glyphs.ts` と同じ経路でメッシュ化し、グリフと同様に TSL マテリアルを適用する。
- 円相も**粒子化の対象にする**と、円が散って再凝集する演出がそのまま得られる。断片パスが多いので粒子サンプル数は面積比で配分する。
- 出現アニメーションは筆の運びに沿って現れる（円弧に沿った線形の露出）のが自然。パスを角度でソートしておくと実装しやすい。

## グリフ SVG の形式

`assets/svg/*.svg` は全ファイルで統一されている（`width/height=100`、`viewBox="0 0 100 100"`、`<g clip-path>` + 単一 `<path fill="white">`）。ビルドスクリプトはこの前提を検証してから読み込む。
