# ルート画面（L0・全文の格子）

## メタファー: 写経の紙面

格子レイアウトの由来は**写経の紙面**である。この一点が以降の判断すべての根拠になる。

- 均質な升目に文字が整然と収まっている状態そのものが、第 1 層の絵になる。
- だから**意味による分節をしない**。写経の紙面に意味の区切りは書かれていない。
- だから**紙面は画面に収まらない**。紙は画面より大きいのが自然な状態である。

## 格子の組み方

- 全文を格子として配置する。**意味による改行・分節は行わない**。等間隔の格子を機械的に敷き詰める。
- **列の切れ目は `content/sutra.txt` の改行位置に従う。** 1 行 = 1 列で、次の行は必ず新しい列の上端から始まる（題名・「即説呪曰」・真言・「般若心経」がそれぞれ独立した列に立つ）。現在 20 列。
- `COLS_PER_LINE = 16`（`src/content/sutra.ts`）は 1 列に収まる字数の**上限**。これを超える行だけが次の列へ折り返す。
- **格子座標は割り算で求めない。** 写像は `src/content/sutra.ts` の `GRID_CELLS` が持ち、描画側（`Paper.tsx` / `PaperFallback.tsx`）は表を引く（`cellOf()`）。逆引きは `indexAt(column, row)`。
- 縦組みの読み順に従い、**列は右から左へ、文字は上から下へ**進む。1 行 = 縦 1 列。
- 字送り・行送りは等間隔。各文字は基準位置から微小にゆらぐ（→ `ink-visuals`）。
- 行数・列数はデータから導出する。ハードコードしない。

```
       ← 列の進行方向（右から左）

  列1  列2  列3  …
   ↓    ↓    ↓
  文字  文字  文字      ┐
  文字  文字  文字      │ 最大 16 文字
  文字  文字  文字      │
   …    …    …        ┘
```

## 画面外へはみ出してよい

**PC・スマホの区別なく、格子は左へはみ出す前提で設計する。** ビューポートに収めるための縮小・折り返し変更・段組み変更は一切行わない。

- 字の大きさは**可読性から決める**（画面幅から逆算しない）。結果として紙面が画面より広くなるのは正しい状態。
- はみ出し方向は**左**。縦組みで列が右から左へ進むため、未読領域は常に左にある。
- 縦方向（1 列ぶん）は**等倍では**画面高に収める。**はみ出すのは横方向のみ**。これにより「1 列は必ず読み切れる」状態を保つ。
- 初期カメラ位置は**紙面の右上**、すなわち第 1 列の先頭。
- **紙面が余白ごと画面に収まってしまう画面では、右端ぞろえにせず中央ぞろえで固定する。** 送り先が無いのに右へ寄せると、左に大きな空白が空いて紙面が画面の隅へ追いやられて見える。

移動・拡大の仕様は `pan-zoom` を参照。

## 意味の区切りは L1 から

- **L0 では意味の区切りを一切見せない。** 格子は均質な紙面として提示する。
- 句としてのまとまりが現れるのは **L1 以降**。
- L0 での hover / フォーカスは、**一定範囲の文字だけが光る**表現とする。範囲は連続した文字インデックスなので、格子上では列をまたぐことがある。**升目の途中で切れて次の列へ続く見え方をそのまま許容する**（範囲を升目に合わせて調整しない）。
- 光るのは文字のみ。升目の枠線や範囲を囲う図形は描かない。周囲は沈む（`dim`）。
- この「紙面は均質なのに、触れると意味の切れ目が浮かぶ」ギャップが L0 の体験の核になる。

範囲は `kind: phrase` のノードが持つ文字インデックス範囲（→ `sutra-content`）。

## 紙面のマテリアルと寿命

- **紙面は畳まない。** 潜っているあいだも置いたままにし、描かず・フレームの計算もせず・当たり判定にも出さないだけにする（`Paper` の `live`）。マウントし直すと 90 字ぶんの用意を 1 フレームで払って固まる。詳細は `transition-fx` の「面の用意はやり直さない」。
- **マテリアルは字ごとではなく紙面で 1 本。** ムラの種・フォーカス量・持ち越しはすべてインスタンス属性で持たせてあるので、シェーダそのものは字によらず同じ。
- 沈み込み（`dim`）も 1 本で、進めるのは `Paper` 本体だけ（字ごとに寄せると 1 フレームで 90 回進んでしまう）。
- **当たり判定用オブジェクトを `visible={false}` にしない**（レイキャスト対象から外れる）。透明マテリアルで置く。
