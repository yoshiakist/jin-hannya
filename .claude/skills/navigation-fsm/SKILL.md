# ナビゲーション

## 状態機械

ズーム中の多重クリックを殺すため、遷移相を明示的に持つ（`nav/fsm.ts`）。

```
idle ──hover──▶ hovered ──click──▶ zooming-in ──▶ focused
  ▲                                                 │
  └──────────── zooming-out ◀──back / breadcrumb ────┘
```

- **`zooming-in` / `zooming-out` の間は入力を無効化する。**
- `focused` からの子ノードへの遷移も同じ相を通す。
- 演出の尺は `scene/Transition.tsx` が持つ（→ `transition-fx`）。

## URL 同期

- `/#/goun/shiki` のようにノードパスを URL に載せる。ハッシュルーティング（`nav/router.ts`）。
- **ブラウザバック = ズームアウト** に割り当てる。共有リンクとしても機能する。

## 現在位置インジケータ

モックには無い追加要件。

- 画面端に **1 本の白い縦線**を引き、その横に先祖ノードを**縦に積み上げる**。
- 文字は**筆文字ではなく通常書体**（可読性優先）。大書との役割を明確に分ける。字だけが要るので `labelText()` を通す（→ `sutra-content`）。
- 各項目はクリック可能。押すとその階層まで一気にズームアウトする。
- 深さ = 潜水深度のメタファー。下端に薄い深度線を引くと『深般若』の名に合う。

## 左矢印

- モックの「左にコンテンツがある」印をそのまま採用。細い白線の矢印のみ、左下。
- **PC・スマホ共通でドラッグによる左パン。** 操作を出し分けない（→ `pan-zoom`）。
- パン可能な方向を矢印の明滅で示す。左端に到達したら明滅を止める。
- 拡大中はドラッグが縦にも効くが、矢印は左端の判定だけを見るので意味は変わらない。
- **L1 以降でも、本文が画面より広いときだけ出す。** 送り先が無い画面では出さない（示唆が嘘にならないようにする）。

## 読み上げボタン

- 画面右上。ピル型の枠線 + スピーカーアイコン。
- 再生中はボタンが状態を示し、もう一度押すと停止する。
- **音源が未収録のノードではボタンを非表示にする**（無効状態で置かない）。
- 再生仕様は `audio-design`。

## 関連

- 遷移演出の尺とカーブ → `transition-fx`
- パンと可動域 → `pan-zoom`
- 画面上の配置 → `node-screen`
