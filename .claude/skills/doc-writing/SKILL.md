# 原稿の深度別ポリシー

**深さは情報量ではなく役割で分かれている。** 下へ行くほど詳しくなるのではなく、下へ行くほど**別のことを語る**。
同じことを詳しく言い直すだけなら潜る意味がない。各層は前の層が触れなかった側を引き受ける。

置き場所とスキーマは `sutra-content` が正典。ここで決めるのは**何をどう書くか**だけ。

## 深度の決め方

原稿の水準は、そのノードが**グラフ上で根から何段目にあるか**で決まる。`kind`（`sutra` / `phrase` / `term`）では決めない。

| 深度 | ノード | 役割 |
|---|---|---|
| L0 | `shingyo`（全文の紙面） | 経そのものの紹介。何が説かれているかを一段落で |
| L1 | 経文の大きな句 | **簡訳。** 中学生でも分かる平たい日本語 |
| L2 | 句の中の句 | **訳注。** 高校生でも分かる範囲で術語を導入する |
| L3 | 語 | **詳細な訳注。** メタ的な概念語を使ってよい |
| L4 | 語の構成要素 | **原義。** サンスクリットの語形に踏み込んでよい |
| L5 | さらに下 | **教学。** 唯識・中論など後代の学派の観点を引いてよい。分量も多くてよい |
| L6 以降 | さらに下 | L5 に準ずる |

**L2 まで読めば般若心経の大意を掴める**——これが梯子全体の設計目標。L3 以降は「もっと知りたい人が潜る先」であって、
ここを読まないと意味が通らない、という書き方をしてはいけない。

将来ノードが複数の経路から届くようになったら、**いちばん浅い経路の深度**に合わせる。深い方に合わせると浅い読者が落ちる。

**隣接ノード**（`anchor` を持つ語 → `sutra-content`）は、深度を持たない。原稿の水準は**アンカーと同じ層**に
合わせる（`種子` はアンカーが L5 の `阿頼耶識` なので L5 = 教学）。別の層から横に入ってきた読者には
一段深い文章になるが、関連語句は「気になったら行く」ものなので、そこは揃えにいかない。

## L1 — 簡訳

対象は**中学生**。経文を読んだことのない人が、ここだけ読んで話の筋を追える状態を作る。

- **仏教の術語をそのまま出さない。** 〈五蘊〉は「自分をかたちづくるもの」、〈空〉は「それだけでは成り立っていない」のように、
  日常語へ開いて言う。術語を出したいという欲求は L2 に預ける。
- 経文の語順・句の順に沿って訳す。解説ではなく**訳文**なので、経文が言っていない主張を足さない。
- 固有名（観自在菩薩・般若波羅蜜）だけは残してよい。読めない字にはルビ `《》` を振る。
- 一文を短く切り、体言止めと漢語の連続を避ける。
- 抽象語で締めない。「苦しみが自分を縛らなくなった」のように、**変化した事態**として書く。

手本: `content/docs/kanjizai-to-issaikuyaku.md`。〈五蘊〉〈空〉〈度〉のいずれも語としては出さずに訳しきっている。

## L2 — 訳注

対象は**高校生**。ここで初めて術語が導入され、**この経の大意が閉じる**。

- **術語は〈〉で括って、その場で定義する。** 定義は一文で足りる長さにする。定義せずに使う術語を残さない。
- 読みが自明でない語にはルビ `《》`。L2 が術語の初出になるので、ここは惜しまず振る。
- 語釈 → 句全体の意味、の順で運ぶ。個々の字を解いてから、それが合わさって何を言っているかを最後にまとめる。
- **一言でいえばどうなるか**を必ず一度書く。〈空〉のような多義の語ほど、暫定的な一文の定義を先に置いてから含みを足す。
- 学説の分岐・異訳・語源には立ち入らない。それは L3 と L4 の担当。

手本: `content/docs/shoken-to-kaiku.md`。〈五蘊〉〈照見〉〈空〉を順に定義し、最後に句全体へ戻して閉じている。

## L3 — 詳細な訳注

対象は**関心を持って潜ってきた読者**。ここから語り口が変わる。

- **メタ的な概念語を解禁する。** 「現出」「表層」「構造」「作用」「条件」「関係」といった、
  経文の語彙ではなく**説明のための語彙**をここから使う。L1・L2 では使わない。
- 説明の対象が「その語の意味」から「**その語がなぜそう立てられているか**」へ移る。
  分類なら分類の狙い、要素なら要素どうしの関係を書く。
- 経文が採らなかった見方や、並列に見えて実は順序があるといった**構造の指摘**をしてよい。
- ただしサンスクリットの語形分析はまだ出さない。ここは漢語の枠内で構造を語る層。
- 断定を避けた含みの持たせ方（「と読むこともできる」）はこの層から許す。L1・L2 では読者を迷わせるので使わない。

手本: `content/docs/goun.md`。五つを列挙したうえで、分類の目的そのものを主題に引き上げている。

## L4 — 原義

対象は**語そのものに用がある読者**。

- **サンスクリットの語形・語根・接頭辞に踏み込んでよい。** 翻字はラテン翻字（`vijñāna`・`rūpa`）で書き、
  カナは YAML の `sanskrit.kana` に任せる。本文でカナと翻字を二重に持たない。
- 漢訳がその原語のどの側面を掬い、どの側面を落としたかを書いてよい。
- **経文中の位置づけ**（なぜこの順に置かれるか、なぜ経文がここを省略するか）を書ける唯一の層。
- 語源の話で終わらせない。原義から出発して、その語が経の主題にどう繋がるかまで一度は戻す。

手本: `content/docs/shiki-vijnana.md`（`vi-` の分析から識の層の展開まで）、`content/docs/shiki-rupa.md`（`rūpa` の原義から経文の配列の理由まで）。

## L5 — 教学

対象は**この語を軸に仏教思想を辿りたい読者**。ここまで来れば、般若心経という一経の枠を出てよい。

- **唯識・中論をはじめとする後代の学派の観点を引いてよい。** 経が言っていないことでも、その語をめぐって
  積み上げられた議論として書ける。教学の術語（分別・戯論・種子・薫習・転依 など）も、一言添えれば使ってよい。
- **学派の立場を混ぜない。** 唯識の説明と中論の説明は分けて書き、そのうえで両者がどこで交わるかを示す。
  どちらか一方を正解として扱わない。
- **典拠を持たない断定をしない。** 学説として言われていることと、こちらの読み筋は書き分ける。
  文献名は挙げてよいが、原典の引用は最小限にとどめ、地の文で言い直す。
- **分量の上限を緩める。** ここは長くてよい。ただし段落の長さは全層共通の約束（3 文前後）を守る。
- **必ず心経へ一度戻す。** 教学の紹介で終わらせず、その観点が経文のどの句をどう読ませるかまで書く。
  ここを省くと、辞書の項目が並んでいるだけの層になる。
- 上の層で使った語（表層・構造・現出）はそのまま使ってよい。L3 で導入した語彙の延長線上にある。

手本: `content/docs/zengo-shiki.md`（唯識の相分・見分と『中論』の眼の検討を並べ、経文の三重の否定へ戻す）、
`content/docs/araya-shiki.md`（種子と薫習から不常不断へ、最後に空へ戻す）、
`content/docs/kunju.md`（隣接ノード。薫習が成り立つのは無自性だからだ、という一点へ寄せる）。

## L0 — 全文

梯子の外側。経そのものの紹介文で、深度別の語彙制約は掛からない。
「これから何へ潜っていくのか」の見取り図を兼ねるので、下の層の結論を先取りして構わない。

手本: `content/docs/shingyo.md`。

## 全層に共通する約束

- **経文本文・解説文をコードや README、コミットメッセージに複製しない**（`CLAUDE.md`）。原稿の出所は `content/` だけ。
- 縦書きの DOM に流れる。半角英数字は寝るので、ラテン翻字を使う L4 以外では避ける。箇条書きは使えるが、
  表と画像は使えない。
- 見出し（`#`）を本文に置かない。段落だけで構成する。
- 一段落は 3 文前後。縦組みで読むため、長い段落は目で追えなくなる。全体の長さは深いほど伸びてよいが、
  段落の長さは深度によらず一定に保つ。
- ダッシュ `——` と三点リーダ `……` は使ってよい。感嘆符は使わない。
- 断定と留保を混ぜない。一つの段落では立場を一つに決める。

## `summary` の書き方

`content/graph/*.yaml` の `summary` は大書の左に出る**数十字の定義**で、解説文とは別物。

- 一文・体言止めでよい。読者を運ばず、**何であるかだけ**を言う。
- **語り口はそのノードの深度に合わせる。** L1・L2 のノードの `summary` に術語を持ち込まない。
- 解説文の冒頭を抜き出したものにしない。`summary` は定義、解説文は展開で、役割が違う。

## 点検

原稿を書いたら次を確かめる。

1. **語彙テスト** — L1 に術語が漏れていないか。L2 に定義なしの術語がないか。L3 より上にメタ概念語が漏れていないか。L4 より上に翻字が漏れていないか。L5 より上に学派の名や教学の術語が漏れていないか。
2. **自足テスト** — その層だけを読んで意味が通るか。下の層を読まないと分からない書き方になっていないか。
3. **非反復テスト** — 親の原稿と同じことを詳しくしただけになっていないか。親が触れなかった側を引き受けているか。
4. `npm run content:validate` — `id` とファイル名の対応、`docs/*.md` の欠落を見る（文章の中身は検証されない）。
