# 読破の記録 — 紙面を青くしていく

## 何のための仕掛けか

**紙面ぜんたいを青くしたい、と思わせるためのもの。** 一度下りた語は L0 に戻っても青白く灯り続け、まだ墨のままの列が残りとして見える。全文 20 列を順に潰していく張り合いが、この作品での「続きを読む理由」になる。

飾りではないので、次の 2 つを崩さない。

- **達成可能であること。** グラフは長大になる前提で、配下を全部舐めさせる条件にすると誰も達成しない。
- **紙面の静けさを壊さないこと。** 青は点いたままにする。明滅・呼吸・誘目のアニメーションは足さない。

## 判定は深さで決める（鍵は YAML に書かない）

```
読破(node) = その語に属するどこか一本が、要る深さまで訪れている
要る深さ   = min(READ_DEPTH, その枝が実際に持つ最深)
```

- `READ_DEPTH = 3`（`src/nav/progress.ts`）。**L3 まで下りたら読破**とする。例: 五蘊。
- **枝が浅ければその枝の最深に丸める。** 般若心経のように子を持たない語は L1 に着いた時点で読破、摩訶般若波羅蜜多心経のように L2 で尽きる語は L2 で読破。
- **一本でよい。** 兄弟をすべて見る必要はない。五蘊の下の色・受・想・行・識を全部開かなくても、五蘊に着いた時点でその句は青くなる。
- **YAML に完了条件を書かない。** 深さの違いは既にグラフが持っている。ノード側に鍵を持たせると、`children` を足すたびに人の手で更新が要り、必ず片方が腐る。
- **深度の数え方は README と同じ**（根 = L0、その子 = L1）。**隣接ノード（`anchor`）は深度を増やさない**ので、帰属先と同じ深さの語として数える。隣接語を開いても深くは潜っていない。

原稿を足して枝が伸びると、要る深さは `READ_DEPTH` で頭打ちになる。だから**後から原稿を足しても、既に青い語が暗く戻ることはない**（`READ_DEPTH` そのものを上げたときだけ戻る）。

## 記録

- 持つのは**訪れたノード id の集合だけ**。読破したかどうかは保存しない（毎回グラフから導く）。判定規則を変えたときに、古い保存値と食い違わせないため。
- キーは `jin-hannya:visited:v1`。規則を変えるときは `v2` にせず、**保存の形（id の配列）が変わるときだけ**上げる。
- 書き込むのは相が `idle` に落ちたときだけ（`App.tsx` の `useVisitLog`）。遷移中に書くと、途中で引き返した行き先まで訪れたことになる。
- **localStorage は必ず投げうる**（プライベートモード・容量超過）。読み書きは握り潰し、記録できない環境では今回のセッションぶんだけ生きる。壊れた値・消えたノードの id は読み込み時に捨てる。
- サーバへは送らない。アカウントも同期も持たない。

## 見せ方

- **L0 だけ。** 青白くなるのは紙面の字（根の子＝句の `range`）で、L1 以降の大書や図には出さない。潜った先で自分の足跡を見せても、いま読んでいる語の邪魔になる。
- **二値。** 途中経過は出さない。「まだ墨／もう青い」の 2 状態で紙面が読めることが張り合いになる。進み具合は `progressOf` で取れるが表示には使っていない。
- 色は `--visited` / `--visited-glow`（→ `ink-visuals`）。**琥珀とは役割が違う。** 琥珀 = いま触れている一時的な状態、青白 = もう下りた残り続ける痕跡。**触れているあいだは琥珀が勝つ**（`aVisited` の上に `aFocus` を混ぜる）。
- 滲みは hover と同じ距離場の仕掛けを使い回す（`SdfGlow`）。色と強さだけが違い、`VISITED_GLOW_STRENGTH` は琥珀の `GLOW_STRENGTH` よりはっきり弱くする。上げると紙面がイルミネーションになり、いま触れている字が読み取れなくなる。
- 点き方は hover と同じ `FOCUS_FADE` で寄せる。戻ってきた紙面でじわりと点く。
- Tier 3（DOM 紙面）にも出す（`.paper-fallback__char.is-visited`）。GPU レイヤーが無くても記録は同じものを引く。
